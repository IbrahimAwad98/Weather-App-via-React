# Weather App via React

[![CI](https://github.com/IbrahimAwad98/Weather-App-via-React/actions/workflows/ci.yml/badge.svg)](https://github.com/IbrahimAwad98/Weather-App-via-React/actions/workflows/ci.yml)

En modern väderapplikation byggd med React, Next.js och TypeScript.

## Om projektet

Weather App via React är en webbaserad applikation där du snabbt kan söka och se aktuell väderinformation för valfri stad. Applikationen hämtar väderdata från tredjeparts-API:er och presenterar det på ett användarvänligt sätt.

## Funktioner

- Sök efter väderinformation i olika städer.
- Visar temperatur, väderstatus, vindhastighet och luftfuktighet.
- Lyhörd design för både dator och mobil.
- Byggd med Next.js och TypeScript.

## Teknologier

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- JavaScript
- CSS

## Installation och användning

1. **Klona repot**
   ```bash
   git clone https://github.com/IbrahimAwad98/Weather-App-via-React.git
   cd Weather-App-via-React
   ```

2. **Installera beroenden**
   ```bash
   npm install
   ```

3. **Starta utvecklingsservern**
   ```bash
   npm run dev
   # eller
   yarn dev
   # eller
   pnpm dev
   # eller
   bun dev
   ```
   Öppna [http://localhost:3000](http://localhost:3000) i din webbläsare för att se applikationen.
